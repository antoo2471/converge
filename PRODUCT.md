# Converge

Le composeur présente le choix du modèle à côté d’Envoyer et regroupe pièces jointes, collage et comparaison dans un menu « + ». Aucun bouton de génération d’images, panneau de réglages ni texte d’aide permanent dans cette barre. Référence de composition : simplicité d’un composeur moderne, sans reproduction pixel pour pixel de Claude.

Le studio d’images autonome est retiré à la demande de l’utilisateur. Aucun écran de galerie, entrée de navigation ou raccourci vers ce studio ne doit être réintroduit.

Client desktop universel Tauri 2, Rust, React et TypeScript. Le contexte appartient à l'utilisateur et reste dans SQLite local. Installation vide ; Local AI, Custom API et ChatGPT via Codex OAuth sont implémentés. Aucune réponse simulée.

Public : utilisateurs techniques et créatifs souhaitant travailler avec leurs modèles locaux ou endpoints compatibles. Scène principale : conversation prolongée sur ordinateur, lecture, code et interfaces interactives.

Priorités : connexions réelles, streaming annulable, contexte explicite, Generative UI déclarative validée, artifacts isolés, permissions intégrées au chat et appliquées dans Rust et secrets hors des exports.

Direction imposée par le brief : finition desktop sobre comparable à Linear/Raycast, typographie précise, thèmes clair/sombre, sans glassmorphism, glow ni grands dashboards. Langue française par défaut (hypothèse de travail). Application native construite directement en code ; travail autonome demandé explicitement.


## Correction utilisateur — 25 octobre 2026

Demande suivante : une bibliothèque de plugins recherchable avec catégories remplace les boutons de connexion par marque. Elle ne contient que les plugins utilisables ; chaque entrée provient du registre. ChatGPT propose uniquement une connexion OAuth propre à Converge. Le mode Chat grand public et la session Codex existante sont retirés. Le vrai logo apparaît dans la bibliothèque, la configuration, les connexions et le rail des modèles, avec une seule variante visible à la fois.

La bibliothèque de marques est retirée. Les fournisseurs sont ajoutés uniquement par formulaire personnalisé : format des requêtes, URL, clés, headers, modèles et capacités. Aucun fournisseur ni serveur prédéfini. La direction visuelle initiale est remplacée par les captures de l’application musicale fournies par l’utilisateur : rail étroit, fenêtre chaude immersive, typographie plus forte, contrôles intégrés et paramètres en panneau. Le collage d’images par Ctrl+V est une exigence de base. L’utilisateur souhaite voir ces corrections avant de nouvelles campagnes de tests.
